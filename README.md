Lista de Compras 
Aplicação web para gerenciamento de listas de compras com cálculos automatizados e interface adaptável para dispositivos móveis.

Funções Principais
Cálculo Automático: Soma o total da compra e subtotais por item em tempo real.

Interface Dual: Alterna entre tela de cadastro e tela de resumo sem recarregar a página.

Limpeza Rápida: Botão para resetar todos os dados da sessão com um clique.

Validação de Dados: Impede a entrada de valores negativos ou campos vazios.

Diferenciais Técnicos
Tabela Inteligente: No celular, a tabela se transforma automaticamente em cartões (cards) para melhor leitura.

Variáveis CSS: Centralização de cores e estilos para facilitar futuras mudanças visuais.

JavaScript Vanila: Código leve, sem dependência de bibliotecas externas, garantindo alta performance.

Tecnologias Utilizadas
HTML5: Estrutura semântica.

CSS3: Flexbox e Media Queries para responsividade.

JavaScript: Manipulação dinâmica de elementos (DOM).

Como Executar
Salve o código em um arquivo .html.

Abra o arquivo em qualquer navegador moderno.

Preencha os campos de item, quantidade e preço para iniciar sua lista.
